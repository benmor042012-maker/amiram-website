# Family Roofing Inc. — website

Static website for [Family Roofing Inc.](https://familyroofinginc.com), a roofing contractor in Los Angeles.

## Stack

- Plain HTML, CSS and vanilla JavaScript, generated by a tiny zero-dependency Node script (`build.mjs`).
- No framework, no CMS, no paid services.
- Output goes to `dist/`, which can be hosted on any static host (Netlify, Cloudflare Pages, GitHub Pages, cPanel upload, etc.).

## Commands

```bash
npm run build   # generate ./dist
npm run serve   # build and serve on http://localhost:8080
```

## Where things live

| Part            | File |
|-----------------|------|
| Page shell, header, footer | `src/layout.mjs` |
| Home page sections (hero, services, projects, form) | `src/pages/home.mjs` |
| Page list       | `src/pages.mjs` |
| Styles          | `src/static/assets/css/style.css` |
| Behavior        | `src/static/assets/js/main.js` |
| Images          | `src/static/assets/img/` |
